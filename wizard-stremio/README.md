# Wizard Stremio para Kodi

Instaladores del perfil Torrentio con Titan Bingie Mod, Jacktook y TMDb Helper.

| Dispositivo | Instalador | Kodi |
| --- | --- | --- |
| Windows | [ZIP 1.3.0](windows/plugin.video.perfil.torrentio-1.3.0.zip) | Kodi 21 Omega. La intro integrada de Bingie Mod y el menú se comprobaron en Windows 21.2. |
| CoreELEC | [ZIP 1.3.0](coreelec/plugin.video.perfil.torrentio-1.3.0.zip) | Preparado para el TV box con Kodi 21.3. La nueva versión queda por probar en el dispositivo. |
| Android y Android TV | [ZIP 1.3.0](android/plugin.video.perfil.torrentio-1.3.0.zip) | Preparado para Kodi 21.3. Queda por probar en el dispositivo. |

La instalación en LibreELEC queda por comprobar.

1. Abre el archivo de tu dispositivo en GitHub y usa **Download**.
2. Crea o activa el perfil **Torrentio** en Kodi.
3. Selecciona el ZIP descargado en **Complementos → Instalar desde un archivo ZIP**.
4. Abre **Perfil Torrentio para Kodi → Asistente de instalación y cuentas** en una instalación nueva. Si ya tienes el perfil configurado, elige **Aplicar cambios al perfil Torrentio**.
5. Abre **Configuración** en el menú principal para acceder al reproductor, Jacktook, subtítulos, fuentes, catálogo y Titan Bingie Mod.

Cada instalación vincula sus cuentas desde Kodi.
