# Wizard Stremio para Kodi

Instaladores del perfil Torrentio con Titan Bingie Mod y Jacktook para Kodi 21 Omega.

| Dispositivo | Instalador | Comprobado |
| --- | --- | --- |
| TV box con CoreELEC | [ZIP 1.0.0](coreelec/plugin.video.perfil.torrentio-1.0.0.zip) | Configuración preparada en un X96 Mini con Kodi 21.3 |
| Windows | [ZIP 1.2.1](windows/plugin.video.perfil.torrentio-1.2.1.zip) | Menú y widgets comprobados en Kodi 21.2. Incluye la corrección para Python 3.8 |

La instalación en LibreELEC queda por comprobar.

1. Abre el archivo de tu dispositivo en GitHub y usa **Download**.
2. Crea o activa el perfil **Torrentio** en Kodi.
3. Selecciona el ZIP descargado en **Complementos → Instalar desde un archivo ZIP**.
4. Abre **Perfil Torrentio para Kodi → Asistente de instalación y cuentas** y sigue la configuración.

Cada instalación vincula sus cuentas desde Kodi.
